## Ответы на вопросы

**1. Чем `int.TryParse()` безопаснее `int.Parse()`? В каких случаях стоит использовать каждый?**

`int.Parse()` выбрасывает исключение `FormatException`, если строка не является числом, - программа аварийно завершается. `int.TryParse()` возвращает `bool` (успешно ли преобразование) и записывает результат в `out`-параметр, не выбрасывая исключений.

- `int.TryParse()` - при вводе данных от пользователя (возможны опечатки, буквы, пустая строка).
- `int.Parse()` - когда данные гарантированно корректны (константы, значения из проверенного источника).

**2. Когда `switch` удобнее, чем цепочка `if/else if`? Приведите пример из реальной жизни.**

`switch` удобнее, когда одна переменная сравнивается с несколькими конкретными значениями. Пример: обработка пунктов меню банкомата - «1 - баланс, 2 - снять, 3 - пополнить, 4 = выйти». Такой код читается лучше, чем длинная цепочка `if/else if`, и легче расширяется.

**3. Что произойдёт в `switch`, если убрать `break` после одного из `case`?**

Выполнение «провалится» в следующий `case` (fall-through). Это может быть намеренно - например, для группировки `case 1: case 2:` - но чаще приводит к логической ошибке. В C# каждый непустой `case` обязан завершаться `break`, `return`, `goto` или `throw`.

**4. Чем отличается `=` от `==` в C#? Почему это частая ошибка?**

- `=` — оператор присваивания (записывает значение в переменную).
- `==` — оператор сравнения (возвращает `bool`).

В математике «равно» пишется одним знаком, поэтому новички интуитивно ставят `=` в условиях. Компилятор обычно ловит такие ошибки, но с `bool`-переменными (`if (flag = true)`) может не выдать предупреждение.

## Итоговая таблица: что изучили

| Команда / элемент | Что делает |
|---|---|
| `if (условие) { ... }` | Выполнить блок кода, если условие истинно |
| `else { ... }` | Выполнить блок, если условие ложно |
| `else if (условие) { ... }` | Проверить следующее условие, если предыдущее ложно |
| `&&` | Логическое И — оба условия должны быть `true` |
| `\|\|` | Логическое ИЛИ — хотя бы одно условие `true` |
| `!` | Логическое НЕ — инвертирует значение условия |
| `условие ? A : B` | Тернарный оператор — вернуть A, если `true`, иначе B |
| `switch (x) { case ... }` | Выбор ветки по конкретному значению переменной |
| `break` | Выйти из блока `switch` (обязателен в каждом `case`) |
| `default:` | Ветка `switch` по умолчанию (аналог `else`) |
| `Random random = new Random()` | Создать генератор случайных чисел |
| `random.Next(1, 101)` | Получить случайное число от 1 до 100 включительно |
| `int.TryParse(str, out int val)` | Безопасно преобразовать строку в число |
| `continue` | Перейти к следующей итерации цикла |
| `int.Parse(str)` | Преобразовать строку в число (может выбросить исключение) |
| `double.Parse(str, CultureInfo.InvariantCulture)` | Преобразовать строку в `double` независимо от локали (точка как разделитель) |
| `Console.ReadLine()` | Считать строку, введённую пользователем |
| `Console.WriteLine(...)` | Вывести строку в консоль |
| `$"текст {переменная}"` | Интерполяция строк — вставка значения переменной в строку |
| `ToUpper()` / `ToLower()` | Привести строку к верхнему / нижнему регистру |
